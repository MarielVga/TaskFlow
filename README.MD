# Gestión de Tareas | TaskFlow

Proyecto del Módulo 4: Programación avanzada en JavaScript.

## Descripción

Esta aplicación interactiva permite al usuario gestionar eficientemente sus quehaceres diarios. El sistema no solo guarda las tareas localmente, sino que incluye herramientas para importar datos simulados, garantizando un flujo de trabajo fluido.

El usuario puede:

- Agregar título de tarea.
- Agregar descripción de la tarea.
- Agregar fecha límite a la tarea.
- Importar tareas de prueba desde un servidor externo.
- Visualizar todas las tareas pendientes y completadas.
- Marcar tareas como completadas.
- Eliminar tareas de la lista.

## Tecnologías usadas

- HTML5
- JavaScript ES6
- CSS3
- API Rest: JSONPlaceholder

## Conceptos aplicados

- **Programación Orientada a Objetos (POO):** Creación de clases, propiedades y métodos.
- **Manipulación Avanzada del DOM:** Inyección de HTML y delegación de eventos.
- **Estructuras ES6+:** Arrow functions, let/const, template literals, destructuring y spread operator.
- **Manejo de Asincronía:** Promesas mediante `async/await` y consumo de APIs con `fetch()`.
- **Persistencia Local:** Sincronización continua de datos utilizando `localStorage`.

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir el archivo `index.html` en el navegador.
3. Abrir la consola del navegador.
4. Seguir las instrucciones que aparecen en pantalla.
